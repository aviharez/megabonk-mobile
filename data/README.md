# data/

All game content lives here as JSON or `.tres`. Adding content must never need a code change.
Planned layout (filled from phase 1 on):

| Folder / file | Content | Phase |
| --- | --- | --- |
| `characters/` | Characters: "status" ("start" or "unlock"), optional "role" (tag on the character select: "TANK"...), base stats, signature weapon id, passive (id + its numbers: `getting_stale`, `speed_damage`, `overtime`; behavior in `scripts/run/passives.gd`), optional "sheets" by clip (`idle` required, `walk`, `hit`; `res://assets/characters/*.png` + sidecar from `tools/spritecook_shrink.py`), else a code-drawn fallback | 1, 4, 6 |
| `weapons/` | Weapons: pattern, base stats, per-level modifiers. Icon: `assets/icons/weapons/<id>.png` (16x16, imported as Image; none = placeholder glyph). Optional in-run art (`tools/art/run_art.py`; none = code/placeholder look): "shot_sprite" (+ "shot_turns": frames in the strip, frame k points at k * 360 / turns) for shot patterns, puddle cups and rockets; "orbit_sprite" (gnome); "swing_sprite" + "swing_turns" + "swing_lengths" (spin swing: one row of turned frames per blade length) | 1, 2, 6 |
| `tomes/` | Tomes: stat modifiers per level; optional "icon": {"cover": [light, dark] palette colors, "symbol_color", "symbol": up to 5 rows of up to 5 `X`/`.`}, drawn on `assets/icons/book.png` by `scripts/ui/icons.gd` | 2, 6 |
| `items/` | Items: rarity, modifiers, or trigger + chance + effect hooks (format: `scripts/run/item_system.gd`). Icon: `assets/icons/items/<id>.png` like weapons | 2, 6 |
| `enemies/` | Enemies: "desc" (one line for the bestiary, Characters > Critters; required), "dex" (bestiary slot order), optional "tag" (role chip word); role (chaser, pack, shooter, exploder, charger, swarm, ghost, boss), stats, role numbers ("shot", "explode", "charge", "boss"; "shot" and boss "rocks" take an optional "sprite" from `assets/shots/enemy/`, the only art allowed the reserved enemy-shot magenta), "sheet" (`res://assets/enemies/<id>.png` + sidecar .json from `tools/art/critters.py`: open-eye loop, closed-eye blink frames, extra poses such as "charge" / "mouth_open"; a boss sheet may hold named clips from `tools/sheet_clips.py`). Without a sheet, a code-drawn "shape" + "color" (only the Overdue Bill). Motion numbers: `rules/creature_motion.json`; Mega Mole "boss": "dig_time" (burrow clip before hiding), "hit_anim_gap" | 1, 3 |
| `maps/` | "name", "status" ("start", "unlock" = opens when the boss of the "unlock_after" map is defeated, "planned" = shown locked on the map select, needs only "name" and "unlock_after"), optional "thumb" (164x52 1x crop, `tools/art/map_thumb.py`). Map size and "props" (road, garden, house, fence, hedge, pond, tree; solid ones block walkers, plants never do; "building" with "building": a building id = a Town building's lot, solid like a house; any prop or interactable with "requires": a building id is only there while it's built), spawn schedule, "swarms" (SWARM INCOMING), "elites", "final_swarm" (own schedule, endless escalation, coin multiplier, Overdue Bills), "interactables" to place, "merchant" timing, boss hint minute. Read by `Director` and `MapLayout`. Art: "ground_textures" (ground kind or "lawn" -> tiling PNG) and "prop_art" (kind -> {"sprite", optional "ramp" + "colors" recolors per prop color, "variants" (prop color -> other sprite), "repeat"}); kinds without art are drawn in code | 1, 3, 6 |
| `interactables/` | Map objects: "behavior" (paid_chest, free_chest, pot, charge_shrine, risk_shrine, challenge_shrine, merchant, cage, key, altar, portal, town: a Town building's object, "building" names it, its effect comes from the building's level) + its numbers, look ("shape" + "color", or an Image-imported "sprite"), "arrow" color. Used by touching or standing in them (`Interactables`) | 3 |
| `challenges/` | Unlock challenges: "tier" (early, mid, hard), "desc", tracked "stat" (one the run records, listed in `Meta.STATS`), optional "weapon" / "character" filter, "scope" ("run" = in one run, "total" = over all runs), "target", optional "goal": "at_most" (best run at or below the target), "requires" (content id that must be owned, or ""), "reward" (a character, weapon, tome or item with status "unlock"), "price" in coins, "coins" (paid once done, claimed in Quests > Milestones). Every unlock content needs exactly one challenge. Rules in `scripts/core/meta.gd` | 4 |
| `shop/` | Coin shop entries: "kind" "action" (Reroll, Skip, Banish: "action", "charges" per run per level; Skip also "gold"), "toggler" ("charges" = how much can be off at once), or "stat" ("modifiers_per_level"); "prices" one per level; optional "needs": {"runs": n} or {"unlocks": n} | 4 |
| `danger/` | Danger levels (Pick a District, every district): "level" (1, 2, 3... no gaps), "modifiers" ("spawn_rate", "enemy_hp", "enemy_damage" multipliers, "elite_every_sec" [min, max] replacing the map's), "coin_mult" (end-of-run coins). Danger n + 1 opens when the district's boss is beaten on n. Read by `Director`, rules in `scripts/core/meta.gd` | 11 |
| `quests/` | Quests on the challenge schema ("stat", optional "weapon" / "character" filter, "scope" run or total, "target", optional "goal", "requires") plus "kind" ("daily", "weekly", "milestone"), "reward" {"coins", "points" (dailies only: 20 each)} and "repeat" (true for dailies and weeklies, which come back in later draws; false for milestones, claimed once). Optional "danger" (the run must be on this level or higher) and "icon" (`kind/id`: content, `enemies/...`, `interactables/...` or `ui/...`; else the stat's icon in `rules/quests.json`). Milestones of one stat + filters + scope form a chain (lowest unclaimed tier shows). Unlock challenges also pay their "coins" once done. Rules in `scripts/core/quests.gd` | 12 |
| `buildings/` | Town buildings (Town tab, docs/BRIEF.md "Update 1"): "name" (pin), "title" (window), "order", "district" (map id), "sprite" (one picture: ruined = the same drawn darker with boards, `Town.ruin_image`), optional "icon" (Icons ref for the window), "interactable" (its "town" object), "effect_desc" (in-run effect, "{heal}" / "{uses}" / "{pct}" / "{seconds}" filled from the level), "levels": [{"price" (whole coins; none on level 1 of an "unlocks" building: its challenge's price), "patrol" (coins per hour), "effect": {"heal", "buff": {"seconds", "modifiers"}, "pull_gems", "uses", "recharge_sec"}}], and either "unlocks" (content ids; the first decides: ruined until its challenge is done, buildable when it's "available", built when owned; Rebuild = buying it) or "shop" (shop "stat" entries whose level is the building's: they leave the Shop). Rules in `scripts/core/town.gd` | 13 |
| `rules/town.json` | "district" (the Town tab's map), "view" ([x, y, w, h] map rect the Town tab shows at night), "patrol_cap_hours" (Patrol stops earning after this long) | 13 |
| `rules/quests.json` | Quest draws: "daily_count" (drawn at local midnight), "weekly_count" (drawn on Monday), the daily points "chests" [{"points", "coins"}], and "icons" (stat -> icon ref) | 12 |
| `rules/run.json` | Run rules: length, enemy/gem caps, slots, XP curve, coins, gem tiers (optional "sprite" per tier), "default_shot_sprite" (shots that name no look), magnet, fallback cards, gold, shield, burn tick | 1, 2 |
| `rules/loot.json` | Rarities, colors, stacking, legendary limit, luck shift, chest kinds (paid, elite, boss, merchant) and their rarity weights | 2, 3 |
| `rules/audio.json` | The one list of audio files (`scripts/autoload/audio.gd`): "voices" (SFX voice cap), "music" (menu, gameplay, boss OGGs), "music_db", "music_fade", and "sfx": id -> {"file", "db", "pitch" (random +- fraction per play), "max" (voices of this sound at once), "gap" (min seconds between plays), "priority" 0-3}. Swap a sound by overwriting its file. WAVs from `tools/audio/sfxr.py` (recipes in `tools/audio/sfx.json`, same ids), music from `tools/audio/chiptune.py`. Weapons name sounds in "sfx": {"attack", "hit" (default "hit"), "land" (puddles)} and their hit effect in "hit_fx": {"kind": puff / star / sparks, "color", "r"}; enemies in "sfx": {"shoot", "swell", "explode", "windup", "death"} | 7 |
| `rules/fx.json` | Juice and VFX numbers (`scripts/run/juice.gd`, `fx.gd`): hit-stop (big crits, boss hits, boss down), screen shake per cause, low-HP vignette ("below", "band", "beat_sec"), "final_tint" (palette color -> palette color map for the Final Swarm; ENEMY_SHOT can't be a target), level-up burst time, chest beam, death particle pool, gem trails and twinkles, "hit_fx_gap" | 7 |
| `rules/elites.json` | Elite scaling (HP, damage, 2x size, knockback taken, XP), the chest they drop, cage key chance and pity, and the traits (Fast, Shielded, Splitting, Vicious) as speed/damage/HP multipliers, shield share, split count, outline color | 3 |

`export_presets.cfg` includes `data/*` so non-resource JSON files ship in the APK.

Rules for every file: one entry per file, `"id"` equals the file name, colors are palette constant
names from `scripts/core/palette.gd` (for example `"PURPLE"`; `ENEMY_SHOT` is reserved), and numbers
are plain JSON numbers. `GameData` (`scripts/core/game_data.gd`) checks required keys, types, known
roles/patterns/passives/stats, and cross-references, and names the file in every error.
